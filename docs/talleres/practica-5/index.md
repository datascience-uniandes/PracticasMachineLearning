# Práctica 5: Interpretabilidad

En esta práctica se retoman dos modelos de las prácticas anteriores, la **regresión polinomial**
que predice el precio de las casas (Práctica 1) y el **Random Forest** que predice el abandono
de los clientes del banco (Práctica 2), para responder una pregunta que las métricas no
responden: **¿por qué el modelo predice lo que predice?** Se usan tres técnicas de
interpretabilidad: los gráficos ICE, LIME y los valores SHAP.

### Datos de trabajo: [inmuebles.csv](../../datos/inmuebles.md) y [churn.csv](../../datos/churn.md)

la [Actividad 4 de la Práctica 2](../practica-2/actividad-4.md).
