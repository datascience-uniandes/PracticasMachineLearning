# Práctica 2: Clasificación

En esta práctica se analizan los clientes de un banco para entender qué factores se relacionan con
el **abandono** (_churn_) y construir modelos de clasificación que lo predigan: regresión logística,
árboles de decisión, KNN, ensambles y una red neuronal.

### Datos de trabajo: [churn.csv](../../datos/churn.md)

En la página del dataset encontrará el enlace de descarga y el diccionario de datos.
