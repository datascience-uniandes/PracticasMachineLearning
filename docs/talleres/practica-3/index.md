# Práctica 3: Agrupación

En esta práctica se analiza el comportamiento de uso de los titulares de tarjetas de crédito para
encontrar **grupos de clientes** con hábitos parecidos (segmentación). A diferencia de las
prácticas anteriores, los datos no tienen [variable objetivo](../../glosario.md#variable-objetivo):
es un problema de [agrupación](../../glosario.md#agrupacion).

### Datos de trabajo: [tarjetas.csv](../../datos/tarjetas.md)

En la página del dataset encontrará el enlace de descarga y el diccionario de datos.
